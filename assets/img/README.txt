Fart Generator - main images
============================

Drop your own images here. The original game read them from its "img" folder;
this port reads the same folder inside assets/.

Supported: .jpg  .jpeg  .png  .bmp
Sub-folders are scanned only when "Read Recursive" is enabled in the config
(user://fart_generator.cfg).

The three demo_*.jpg files and sample_4.png are placeholders - delete them once
you have added your own pictures. Use Up/Down, the mouse wheel or the
Slideshow button to flip through this folder.

Hole positions are remembered per file name in user://fart_generator.cfg.
